**Technologies:**

## 💊 Counterfeit Medicine Detection System

Developed an image classification system using deep learning and computer vision to distinguish genuine medicine packaging from counterfeit packaging.

The system processes medicine images and predicts whether the product is genuine or counterfeit.

**Technologies:**

`Python` `TensorFlow` `Keras` `CNN` `Computer Vision` `OpenCV`

---

## 🎮 Video Game Sales Prediction using Machine Learning

Built and compared three regression models to predict global video game sales using platform, genre, region, and publisher data.

Models evaluated:

- Decision Tree — R² = 0.85
- Random Forest — R² = 0.84
- XGBoost — R² = 0.81

Integrated a Gradio interface for real-time predictions.

**Technologies:**

`Python` `Pandas` `Scikit-learn` `Decision Tree` `Random Forest` `XGBoost` `Gradio` `EDA`
